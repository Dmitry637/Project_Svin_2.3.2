# Вариант №7 — этап 3 (Python)

Отдельный проект третьего этапа практической работы. Программа получает
POM-файлы Maven, рекурсивно собирает прямые и транзитивные зависимости,
строит граф связей и сохраняет его в SVG-файл. Для чтения POM и создания
изображения используются только модули стандартной библиотеки Python.

## Параметры конфигурации

Параметры задаются в INI-файле:

| Параметр | Назначение |
|---|---|
| `[package] name` | Координаты пакета `groupId:artifactId`. |
| `[package] version` | Версия анализируемого пакета. |
| `[repository] location` | Путь к локальному Maven-репозиторию или URL HTTP(S). |
| `[repository] mode` | Режим репозитория: `auto`, `local` или `remote`. |
| `[visualization] graph_image` | Путь и имя выходного SVG-файла. |

В `config.ini` задан локальный тестовый репозиторий. Он позволяет запустить
проект и проверить построение графа без подключения к интернету.

## Запуск

Требуется Python 3.10 или новее. Дополнительные пакеты устанавливать
не нужно. Команды выполняются из корневой папки проекта.

### Windows

Запуск с настройками из `config.ini`:

```bat
run.bat
```

Выбор другого конфигурационного файла и глубины анализа:

```bat
run.bat --config config.ini --max-depth 3
```

### Linux и macOS

```bash
chmod +x run.sh
./run.sh
```

Для указания глубины анализа:

```bash
./run.sh --max-depth 3
```

### Запуск через Python

```bash
python main.py
python main.py --config config.ini --max-depth 3
```

Параметр `--max-depth` задаёт максимальную глубину графа. Значение `0`
оставляет только исходный пакет, значение `1` добавляет его прямые
зависимости. По умолчанию используется глубина `4`.

## Результат работы

После успешного запуска в файл, указанный в `graph_image`, сохраняется
векторное изображение `dependencies.svg`. Узлы обозначают Maven-пакеты,
стрелки — зависимости между ними. На стрелке указывается `scope`;
необязательные зависимости помечаются `optional`.

Для просмотра результата откройте созданный SVG-файл в браузере или
любом просмотрщике векторной графики.

Пример структуры графа для встроенного репозитория:

```text
com.example:demo-app:1.0.0
├── org.example:demo-core:2.1.0
│   └── org.example:demo-common:1.0.0
└── org.example:demo-utils:1.4.0
```

## Обработка ошибок

При отсутствии POM, ошибке HTTP, некорректном XML или неверной
конфигурации приложение выводит сообщение в `stderr` и завершает работу
с ненулевым кодом возврата. Повторное посещение уже обработанного пакета
не запускает бесконечный обход, поэтому циклические связи не приводят
к зацикливанию.

Если в качестве `repository.location` указан отдельный `.pom`-файл,
программа строит граф исходного пакета и его прямых зависимостей. Для
рекурсивного обхода транзитивных зависимостей нужен каталог Maven-репозитория
или удалённый Maven-репозиторий.

## Тестирование

Запустите модульные тесты:

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют конфигурацию, чтение Maven POM, разрешение свойств,
рекурсивный обход, ограничение глубины, обработку циклов и создание SVG.

## Структура проекта

```text
src/       чтение конфигурации, Maven POM и построение графа
tests/     модульные тесты и локальный тестовый Maven-репозиторий
main.py    точка входа третьего этапа
config.ini конфигурация для запуска без интернета
run.bat   запуск в Windows
run.sh    запуск в Linux и macOS
```

## Ограничения

Реализация обрабатывает зависимости, объявленные непосредственно в POM,
и поддерживает Maven-свойства и локальный `dependencyManagement`.
Она не является полной заменой Maven: наследование эффективного POM,
импорт BOM, профили, исключения и все правила разрешения конфликтов Maven
не реализованы.

## Проверка качества кода

Основное приложение использует только стандартную библиотеку Python.
Дополнительные инструменты нужны только для проверки исходного кода:

```bash
python -m pip install radon pycodestyle ruff
```

Проверка стиля PEP 8:

```bash
python -m pycodestyle main.py src tests
```

Проверка цикломатической сложности:

```bash
python -m radon cc main.py src -s -a
```

Настройка Ruff в `pyproject.toml` ограничивает сложность одной функции
значением 20 и длину строки 79 символами:

```bash
ruff check main.py src tests
```
